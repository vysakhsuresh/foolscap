About Bookmarks

Add, rename, reorder and remove the bookmarks a PDF reader shows as the document’s contents, each pointing at a page. Good bookmarks make a long PDF easy to move around, and Split can cut a file at each one.

How to use it

  1. Add the PDF; any bookmarks it already has appear as a list.
  2. Tap Add a bookmark, then type its title and the page it should open.
  3. Use the arrows to move a bookmark up or down the list, or in a level so it sits under the one above.
  4. Press Save the bookmarks and save the new file.

Good to know

A bookmark is a title and a page. Readers list them in a side panel, often called Contents, Outline or Bookmarks, and tapping one jumps straight to its page. Putting sections inside chapters keeps a long contents list short and easy to scan.

Short titles that match the headings printed in the document work best: Chapter 3, Annexure B, Salary slips. Top-level bookmarks are also what Split uses at each chapter, so a well bookmarked file can be cut into one file per chapter in a single step.

Saving an empty list removes every bookmark, which helps when a file arrives with a messy outline left by the program that made it. The pages, their text and their look are never touched, and a locked PDF stays locked with the same password.

Questions people ask

Where do bookmarks show up?

In the contents or outline panel of most PDF readers, including Read.

Do bookmarks change the pages?

No. They only add a way to jump between them.

Can I make sections inside chapters?

Yes. Move a bookmark in a level and it sits under the one above it, as a section of that chapter.

Is my file uploaded?

No. The bookmarks are written into the file in your browser, on your device.
