About Page numbers

Numbers the pages at the top or bottom, as 1, 1 of 12, Page 1 or Page 1 of 12, starting from any number and skipping a cover if you like. Bates numbering runs one sequence like ACME-000001 through every page of every file you add.

How to use it

  1. Add one or more PDFs.
  2. Choose where the numbers go: top or bottom, left, centre or right.
  3. Choose a style and set First number if counting should not start at 1.
  4. Tick Leave the first page unnumbered if the document has a cover.
  5. Press Add the numbers and save the result.

Good to know

With the cover left unnumbered, counting starts on the second page at your first number, so a report with a cover reads 1, 2, 3 from its first real page. Starting from another number carries on from an earlier volume: a file that follows 40 pages starts at 41.

The numbers are small and plain, set a short way in from the edge, where most layouts leave room. If a page already has something printed in that corner, such as a footer or a logo, choose a different place. Each file you add is numbered on its own, from the first number.

Bates works differently: one running sequence through every page of every file, in the order you added them, with a prefix and a fixed number of digits. Courts and law offices use it so any page in a bundle can be cited by its number alone. The prefix takes English letters, numbers and punctuation.

Questions people ask

Can I start from a number other than 1?

Yes. Set First number.

What is Bates numbering?

A legal numbering with a prefix and fixed digits, running through a whole set of documents in order.

Can I number the front pages i, ii, iii?

Printed numbers here are 1, 2, 3. To have a reader call the front pages i, ii, iii, use Page labels.
