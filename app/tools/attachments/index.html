About Attachments

Puts files of any kind inside a PDF, such as a spreadsheet, photos or the source document, so they travel with it. Or takes out every file a PDF carries, byte for byte. Attached files are carried as they are, never opened or checked here.

How to use it

  1. Choose Put files inside the PDF, or Take out the attached files.
  2. Add the PDF first, then, to attach, the files to put inside it.
  3. Press Attach or take out.
  4. Save the PDF with its attachments, or save each file that came out.

Good to know

Attaching keeps a set together: an invoice PDF with the spreadsheet behind it, a report with its raw photos, a signed form with the scan of the ID it refers to. The receiver opens the attachments panel in their reader and saves each file from there. The PDF grows by about the size of what you attach.

Taking out saves every file a PDF carries, exactly as it went in, with its own name. A PDF that comes out can go straight into another tool. Files attached to a PDF from someone you do not know deserve the care you would give an unexpected email attachment, because nothing here checks them.

Attachments are easy to forget, and they leave with the PDF every time it is sent. To drop them all before sharing, use Clean hidden data. A locked PDF stays locked with the same password when files are added.

Questions people ask

How do I attach files?

Add the PDF first, then the files to put inside it.

Where do attachments show?

In the attachments panel of most PDF readers.

Is there a size limit on attachments?

None is set here; your device’s memory is the only limit. The person receiving it may have an email limit, though.

Are the files uploaded or scanned?

No. They are put inside the PDF in your browser, as they are, and never opened or checked.

How do I remove all attachments?

Clean hidden data takes them out.
