How it works

  1. Pick your PDFs

    Drop them in or tap to choose. They are copied into your browser’s own private storage, on this device.

  2. Do the work here

    Merge, split or reorder. Your browser does it all; there is no server to send anything to.

  3. Save or share

    Save the new file where you like, or send it straight to WhatsApp or email. The file you picked is never changed.

How do we know nothing leaves? Open the Network tab.

Every page here ships a security policy that stops it talking to anything but this site — and this site is a folder of files that runs no code. Turn on airplane mode after a tool page loads and it still works.
