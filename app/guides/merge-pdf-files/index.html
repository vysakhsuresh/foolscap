How to merge PDF files into one

By Layerbit, the makers of Foolscap · Updated 17 October 2026

Open Merge, add the PDFs, drag them into order, and press Merge into one file.

Merge →Free. Nothing is uploaded.

How to do it

  1. Open Merge and add two or more PDFs.
  2. Drag them into order (on a phone, hold a file a moment first), or use the arrows.
  3. Type the password of any locked file in the box under it and tap Unlock.
  4. Press Merge into one file.
  5. Save the merged PDF, or tap Then to hand it to another tool.

Fixing the order inside

Merge puts whole files end to end. To move single pages, turn one round or drop one, open the merged file in Organise pages. The Then button on the result takes it straight there without saving in between.

Photos and PDFs together

Merge takes PDFs. If some of your pages are photos, make them a PDF first with Images to PDF, then merge that with the rest. For a form with an upload limit, Compress the merged file afterwards; see compress to 200 KB.

No limits, because there is no server

Most PDF sites upload your files, so they cap how many and how big. Here the joining happens in your browser, one file at a time, so forty scans cost no more memory than the result plus one. The only limit is what your own device can hold.

Common mistakes

The most common is getting the order wrong and noticing only after sending. The list on the page is the order of the result, top to bottom, so check it before you press the button. Another is merging one huge scan with several small typed files and then finding the result too big to upload: compress the merged file to the limit afterwards, or compress the big scan on its own first.

A worked example

A passport office wants your address proof, date of birth proof and an affidavit as one PDF. Add the three files, use the arrows so they match the order of the checklist, and press Merge into one file. The result is named after the first file with + 2 more, and the line under it gives the number of pages, which should be the three files’ pages added together.

Save it, or tap Then and choose Compress if the upload has a size limit.

Locked files and passwords

Locked files can be merged once you type their passwords. The merged file has no password, because each input may have had a different one, and the result says so. If what you are sending is private, lock the merged file with Add a password and send the password separately, by a phone call or a message.

Pages are copied across as they are, not redrawn, so typed text stays selectable and photos stay exactly as sharp as they were in the files you added.

Questions people ask

How many PDFs can I merge?

As many as your device can handle. There is no cap on count or size.

Are my files uploaded?

No. They are joined in your browser and never leave your device.

Does it change the original files?

No. The merged PDF is a new file. The ones you picked are never changed.

Can I merge on my phone?

Yes. It works in the phone’s browser, and Share sends the result straight to WhatsApp or email on phones that can share files.

Can I merge on a work computer without installing anything?

Yes. It runs in the browser, so nothing is installed, and the files never leave the computer, which matters where company documents must not be uploaded.

What if one of the files will not open?

The others are still merged, and the result names the one that could not be read. If that file is damaged, ask whoever sent it for a fresh copy.
