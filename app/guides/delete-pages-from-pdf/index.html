How to delete pages from a PDF

By Layerbit, the makers of Foolscap · Updated 17 October 2026

Open Extract or remove pages, type the pages to take out, choose Remove these pages and press Make the new file.

Extract or remove pages →Free. Nothing is uploaded.

How to do it

  1. Open Extract or remove pages and add the PDF.
  2. Type the pages to delete, such as 2, 5-6.
  3. Choose Remove these pages.
  4. Press Make the new file.
  5. Save the new PDF.

Seeing the pages first

If you would rather see the pages than type numbers, Organise pages shows every page as a picture. Tap the bin under each page you do not want, then Save the new order. You can also turn and move pages there in the same go.

Deleted means gone

The new file is built from the pages you keep. A deleted page is not hidden inside it; it is not in the file at all.

If only part of a page is private, such as one account number, you do not need to delete the whole page. Remove areas takes out just the parts you mark.

Blank pages from a scanner

Scanners that do both sides of the paper leave a blank page after every one-sided sheet. Type their numbers, such as 2, 4, 6, 8, and choose Remove these pages; or open the file in Organise pages, where blank pages are easy to spot, and tap the bin under each. A file without its blank pages is also smaller, which helps with an upload limit.

A worked example

A bank asks for your salary slip, but the PDF from your employer has four pages: the slip, a tax summary, and two pages of terms. Open Extract or remove pages, add it, type 2-4, choose Remove these pages and press Make the new file. The new file is named with the pages it left out and holds only the slip. Check it, then send that one and keep the full original for yourself.

Common mistakes

Typing the pages to keep while Remove these pages is chosen, or the other way round, is the classic slip. The result line counts what was removed and what is left, so read it before sending. Page numbers printed on the pages may not match the file’s own count, for example when a cover has no number: type the position of the page in the file, as the reader’s page box or Organise pages shows it.

Private pages

Deleting a page from the copy you send is the cleanest way to share less, because the page is not in the new file at all. If the page must stay but carries one private detail, Remove areas takes out only that part. If the file’s hidden details matter as well, such as the author’s name, follow up with Clean hidden data.

The person you send it to can see how many pages the file has. If a missing page would raise questions, say in your message what you left out and why.

Questions people ask

Can I delete every page but one?

Yes. You must leave at least one page.

Does it change the file I picked?

No. Every result is a new file; the original stays as it was.

Is it safe for private documents?

The file never leaves your device: pages are removed in your browser.

I deleted the wrong page. Can I undo it?

Your original file is unchanged, so start again from it. In Organise pages, tapping the bin again brings a page back before you save.

Does deleting pages make the file smaller?

Usually, yes: a page’s own text and pictures leave with it. A page that shared its fonts or pictures with pages you kept saves less.

Can I delete pages on my phone?

Yes. Type the page numbers, or use Organise pages, where each page has a bin button big enough for a thumb.
