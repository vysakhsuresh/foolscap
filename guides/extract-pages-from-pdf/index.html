How to extract pages from a PDF

Open Extract or remove pages, type the pages you want, leave Keep these pages selected and press Make the new file.

Extract or remove pages →Free. Nothing is uploaded.

How to do it

  1. Open Extract or remove pages and add the PDF.
  2. Type the pages to keep, such as 1-3, 7.
  3. Leave Keep these pages selected.
  4. Press Make the new file.
  5. Save it, or tap Then to send it to another tool.

Typing the pages

Separate pages and ranges with commas. 1-3 means pages 1, 2 and 3. 12- means page 12 to the end. 1-3, 7, 12- keeps all three groups, in the order of the original.

When to use it

A portal wants only the first page of a marksheet, or one month from a year of statements, or the signed page of an agreement. Sending only that page keeps the file small and shares less. To bring it under an upload limit as well, follow it with Compress.

Several files from one

Extract makes one new file. To cut a PDF into several files at once, use Split. To change the order of pages, use Organise pages.

The opposite job, taking a few pages out and keeping the rest, is the same tool with Remove these pages chosen; see delete pages from a PDF.

A worked example

A college portal wants only the first page of your 4-page degree certificate PDF, and your final marksheet, which is page 9 of a 10-page file. Open Extract or remove pages, add the certificate, type 1, leave Keep these pages selected, and press Make the new file. Tap Start over, add the marksheet file, type 9 and do the same. Each new file holds just the page the portal asked for, named with that page’s number.

Typing pages without fuss

You do not have to type ranges perfectly. A backwards range such as 9-3 is read as 3 to 9, a page number beyond the end is ignored, -4 means the first four pages, and spaces do not matter. The pages come out in the order of the original whatever order you type them, so if you also want them in a different order, take the result into Organise pages.

Keep, remove, or split?

Keep is quickest when you want a few pages out of many. Remove is quickest when you want most of them, minus a few. Split is for when every page should end up somewhere, in several files. All three leave the original as it was and make new files, so you can try one and then another.

Locked files work the same way: type the password in the box under the file and tap Unlock first, and the new file keeps the same password. The new file is usually smaller than the original, often by more than its share of the pages, because pictures used only on the dropped pages leave with them.

Questions people ask

Does it change my original PDF?

No. You get a new file with only those pages. The original is untouched.

Can I extract pages from a locked PDF?

Yes, with its password. Type it when the file asks.

Is the file uploaded?

No. The new file is made in your browser.

Will the pages lose quality?

No. The pages are copied into the new file as they are, not redrawn, so text stays text and photos are untouched.

Can I take pages from several PDFs into one file?

Extract from each, then join the results with Merge. Or merge first, and extract the pages you want from the merged file.

Can I extract pages on a phone?

Yes. Type the pages in the box just as you would on a computer, and share the new file straight to WhatsApp or email.
